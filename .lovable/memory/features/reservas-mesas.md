---
name: Reservas de mesas
description: Caja/Admin registran reservas; mozos solo consultan; reservas no reemplazan el estado operativo de mesa.
type: feature
---
Las reservas se gestionan como registro independiente por establecimiento y mesa.

- Caja y Admin pueden anotar reservas con mesa, cliente, teléfono, cantidad de personas, horario, estado y notas.
- La reserva no debe reemplazar el estado físico de la mesa: una mesa puede estar ocupada y tener una reserva futura.
- Estados base: confirmada, sentados, cancelada, no vino.
- Visualmente, las reservas deben poder verse como apartado propio y eventualmente como aviso sobre la mesa cuando corresponda.
